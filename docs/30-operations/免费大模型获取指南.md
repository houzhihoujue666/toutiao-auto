# 免费大模型获取指南

> **常青层 · 操作类文档**（`30-operations/`）：跟着代码同步更新，不做冻结。
> 最后核对：**2026-11-14**（智谱；其余服务商为 2026-11-11）。免费政策、模型名、限流规则由各厂商决定，本文只给「去哪找、怎么填」，**不替任何厂商承诺永久免费**。

## 这份文档解决什么

本项目的改写只做一件事：把一段几百字的素材改写成自己的口吻。不写代码、不做复杂推理、不读长文档，所以**免费档的小模型完全够用**，不需要买套餐、不需要充值、不需要显卡。

项目默认走「官方 API + 免费模型」（智谱 `glm-4.7-flash`）。程序只发一条网络请求，不打开网页、不用登录、不怕平台改版。你要做的只有一件：**拿一把免费 Key，粘进设置页**。

> 措辞统一叫「**零大模型费用**」，不写「零成本」——账号、电费、素材本来就不花钱，但别把话说死。

## 三步拿到 Key（以智谱为例，最省事）

| 步骤 | 去哪 | 做什么 |
| --- | --- | --- |
| 1 · 注册 | [智谱开放平台 `open.bigmodel.cn`](https://open.bigmodel.cn/)（备用入口 `www.bigmodel.cn`） | 手机号注册登录即可；**不强制实名**（见下方说明） |
| 2 · 拿 Key | 登录后的**控制台**，找「API Keys / API 密钥管理」 | 点「添加新的 API KEY」，起个名字；创建后**立刻复制**——多数平台只完整显示一次 |
| 3 · 填进来 | 本项目的「设置」页 → 可调设置 | 把 Key 粘进 `llm.api.key`，点「填好了，测试一下」，看到「连接正常」就通了 |

> **关于实名认证**（2026-11-14 核对）：智谱[官方实名认证 FAQ](https://docs.bigmodel.cn/cn/faq/authentication-issues) 原文是「目前调用 API 并不强制要求实名认证，但为确保您的账户安全，我们建议您进行实名认证」。所以注册后不用专门去找认证入口；页面若主动要求，照提示完成一次即可，那是官网自己的流程、跟本项目无关。网上不少第三方教程写「必须实名才能创建 Key」，与官方口径不一致，以官网为准。

地址和模型名**已经默认填好**，不用自己敲：

| 配置项 | 默认值 |
| --- | --- |
| `llm.mode` | `api` |
| `llm.api.baseUrl` | `https://open.bigmodel.cn/api/paas/v4` |
| `llm.api.model` | `glm-4.7-flash` |
| `llm.api.key` | 空（你自己填，只存本机 `data/app.db`） |

> **老版本升级过来的注意**：默认值只对新建的库生效，程序不会覆盖你已经存过的 `llm.api.model`（`INSERT OR IGNORE`）。如果之前存的是老名字 `glm-4-flash`，到设置页「免费 AI 改写」卡片的折叠区把「用哪一家」重选一次「智谱」并保存，或在「可调设置」把「API 模型名」改成 `glm-4.7-flash`，再点「填好了，测试一下」。

设置页还有一张「免费 AI 改写」卡片：三步引导写在明面上，地址和型号已经帮你填好；想换一家再点开折叠区选预设，普通使用完全不用碰技术参数。

> 控制台菜单名、按钮文案各家会改版，**只记入口和菜单名，别记死深层链接**。找不到就进控制台看左侧导航，或在官网搜「API Key」。

## 别的平台怎么找（都是同一套填法）

下面这些服务都兼容 `POST {baseUrl}/chat/completions`，换一家只要改「API 地址」和「API 模型名」两项，Key 换成对应平台新建的那一把。

| 平台 | 官网入口 | `baseUrl` | 模型名示例 | 费用口径（智谱 2026-11-14 复核，其余 2026-11-11） |
| --- | --- | --- | --- | --- |
| 智谱 GLM（默认） | `open.bigmodel.cn` | `https://open.bigmodel.cn/api/paas/v4` | `glm-4.7-flash` | 免费模型，国内直连，中文短文本够用 |
| 硅基流动 | `siliconflow.cn` | `https://api.siliconflow.cn/v1` | `Qwen/Qwen2.5-7B-Instruct` | 免费模型名单以官网「模型广场」为准，说法常有变化 |
| 阿里百炼（通义） | `aliyun.com/product/bailian` | `https://dashscope.aliyuncs.com/compatible-mode/v1` | `qwen-plus` / `qwen-turbo` | 新用户免费额度，**注意有效期** |
| 百度千帆 | `cloud.baidu.com/product/wenxinworkshop` | 控制台里的 OpenAI 兼容入口 | `ernie-speed-128k` | 以官网免费模型列表为准 |
| 火山方舟（豆包） | `volcengine.com/product/doubao` | `https://ark.cn-beijing.volces.com/api/v3` | 控制台里的模型 ID | 以官网免费额度为准 |
| DeepSeek | `platform.deepseek.com` | `https://api.deepseek.com/v1` | `deepseek-chat` | 按量计费（**项目默认不走这一家**） |

**找免费模型的通用路径**（比记具体模型名更耐用）：

1. 进官网 → 登录 → 控制台；
2. 找「模型广场 / 模型列表 / 定价 / 价格」页，筛「免费」或看单价为 0 的文本模型；
3. 复制**准确的模型 ID**（大小写、斜杠都不能改，填错会报 404）；
4. 在「API Keys」页建 Key，回本项目设置页填好，点「填好了，测试一下」。

## 报错了看这里

| 现象 | 多半是 | 怎么处理 |
| --- | --- | --- |
| 「还没填 AI 钥匙」 | 只差第 3 步 | 按上面三步补 Key；设置页「免费 AI 改写」卡片有引导 |
| `401` / `403` Key 被拒绝 | Key 粘错、带了空格，或误用了别家平台的 Key | 重新复制粘贴；确认 Key 与 `baseUrl` 是同一家 |
| `402` / 余额不足 | 选到了付费模型 | 在设置页折叠区换回免费预设，或去服务商控制台看额度 |
| `429` 限流 | 免费档常有每分钟调用上限 | 程序会自动重试（默认 3 次预算），超预算转人工；等 1 分钟再点，或换一家 |
| `404` 地址或模型名不存在 | 模型 ID 拼错，或地址填成网页地址 | 地址一般以 `/v1` 结尾；模型名去官网模型列表复制 |
| 超时 | 网络不通或服务商抖动 | 检查网络；设置页可调「改写等待上限」（默认 120 秒） |
| 返回的不是 JSON | 地址填成了官网首页 | 改回 OpenAI 兼容接口地址 |

相似度过关不了、免费小模型偶尔发挥不稳？项目本来就有兜底：超标会**自动重写一次**，仍不合格就停在「待复核」等人看一眼，不会硬发出去。

## 老用户：要不要切过来

**只提示、不强制迁移。** 旧版本默认 `llm.mode = web`，这个值已经存在你本机的 `data/app.db` 里，改代码里的默认值**不会自动改掉老库**。想切就在设置页把「改写方式」改成 `api`，再按本文三步填 Key。

`web`（网页版 DeepSeek）**没有删**，留着给两种场景：完全离线不想注册任何平台，或官方接口出问题时临时兜底。但网页版依赖登录态和页面元素，平台一改版就可能失效，所以不再当默认。

## 安全底线

- **不内置任何共享 Key**：项目源码里没有、也不会有别人的密钥，每人用自己申请的那一把。
- **Key 只进本机库**：`llm.api.key` 存在 `data/app.db`，`data/` 已被 `.gitignore` 忽略；项目不上传、不收集、不回传。
- **别把 Key 贴进 Issue、截图或公开文档**；换平台时旧 Key 建议去控制台删掉。
- 免费档也可能有调用频率、内容合规等平台侧规则，以各官网服务条款为准。

## 什么时候更新这份文档

免费政策、限流或模型名有变化时，**只改这份 md**（以及 README 的对照表），界面卡片里的接口地址和模型 ID 是技术标识，一般不跟着变。这样不用改代码、不用重新发版；开源后别人也能直接提 PR 帮你更新。

发现某家取消免费了，请把「最后核对」日期一起改掉，并在表格里注明「以官网为准」，不要留着过期的承诺。
