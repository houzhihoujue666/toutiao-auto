# ADR-0016 默认改写走免费 API 并保留网页兜底

## Context and Problem Statement

ADR-13（legacy v4.0 §3.3，2026-10-12 定案）定的是「默认 `llm.mode = web`；`manual` / `api` 为退路，**付费路径不许默认打开**」。当时把「零费用」和「网页版」绑在一起，是因为官方 API 要付费，只有操控网页版 DeepSeek 才能不花钱。

一年下来出现两个新事实：

1. **网页路径不好用**：`web` 依赖浏览器登录态、输入框选择器与「停止生成」按钮，平台改版或登录过期就失效，是实际使用中最常出错的一环；`api` 只用 Node 自带的 `fetch()` 发一条 `POST /chat/completions`，不依赖页面结构。
2. **免费档官方 API 已经普及**：2026 年多家国内平台提供 OpenAI 兼容的免费文本模型（智谱 `glm-4-flash` 等）。「官方接口」与「零费用」不再互斥，ADR-13 的前提被推翻了。

同时，本项目的改写需求始终很低——把一段几百字素材改成自己的口吻，不做推理、不读长文档、不写代码，免费档小模型足够。

于是要重新回答：**默认改写方式该走哪条路，才能既不花钱、又稳、又不踩原来的红线？**

## Decision Drivers

- **保留 ADR-13 的精神**：不许把付费路径默认打开，这条不因技术路线变化而放松
- 稳定性：默认路径不能依赖第三方网页 DOM 与人工登录
- 零大模型费用：面向头条运营者，开箱即用不该有大模型账单
- 合规：走服务商官方接口，比自动化操控网页版更干净，灰区更小
- ADR-10：可调项进 `app_config`，安全项锁死在代码
- 老用户零感知：`INSERT OR IGNORE` 的默认值只对**新装**生效，不能强行改老库
- 对外措辞可辩护：不承诺「永久免费」「零成本」

## Considered Options

- **A：保持 `web` 默认**，只在文档里推荐手动切 `api`
- **B：`api` 设为默认，且默认地址/模型改成免费那套**（智谱 `glm-4-flash`），`web` 保留为兜底
- **C：`api` 设为默认，但沿用原付费默认值**（`api.deepseek.com` + `deepseek-chat`）
- **D：B + 启动时把老库里 `llm.mode = web` 强制迁移成 `api`**

## Decision Outcome

选 **B**。

1. 默认改写方式改为 `api`（`shared/src/constants.ts` 的 `DEFAULT_LLM_MODE`）；
2. **同时**把 `DEFAULT_LLM_API_BASE_URL` / `DEFAULT_LLM_API_MODEL` 一并换成 `https://open.bigmodel.cn/api/paas/v4` / `glm-4-flash`——只改模式不改默认值，等于把新用户直接送进付费通道，违背 ADR-13 的精神；
3. 界面提供免费模型预设一键填充与「三步拿 Key」引导，完整清单放独立常青文档 `docs/30-operations/免费大模型获取指南.md`，**费用口径只写文档、不写死在代码里**（政策变了改 md，不用重新发版）；
4. `web` / `manual` / `simulated` **一律保留**，网页版留作离线与兜底；
5. 老用户**只提示、不强制迁移**：设置页检测到当前仍是 `web` 时给一条温和提示，不写库、不覆盖用户选择；
6. 对外统一说「**零大模型费用**」，不写「零成本」「永久免费」，并标注核对日期。

**ADR-13 的「付费路径不许默认打开」继续有效**，本 ADR 推翻的只是「零费用 = 必须走网页」这个技术前提。ADR-13 在 `decisions/README.md` 的索引行标注 `superseded by ADR-0016`，legacy 原文一字不改。

### Consequences

- Good：默认路径不再依赖网页 DOM 与登录态，最常见的失败来源被移除；且仍然是 0 元。
- Good：走服务商官方接口，规避「自动化操控网页版」的服务条款灰区。
- Good：新人只需注册 → 建 Key → 粘贴三步；设置页引导把这一步从「读 README」变成「照着点」。
- Good：老用户零迁移、零覆盖，符合 ADR-10 与「默认行为不悄悄改变」的惯例。
- Bad：默认 `api` 后，**没填 Key 的新用户点发布会直接失败**。缓解：`ensureSession()` 的报错明确指向设置页引导；设置页卡片在显眼位置；`web` 可随时切回。
- Bad：免费档常有限流（429）与小模型质量波动。缓解：保留现有的 429 预算重试、相似度重写与人工复核闸门，兜底链完整。
- Bad：多了一处「免费模型清单」需要长期维护，且资料来源互相打架。缓解：只给官网入口与菜单名、标核对日期、不写死承诺；清单独立成 md，便于 PR 更新。

### Confirmation

- `shared/src/constants.ts`：`DEFAULT_LLM_MODE = 'api'`，默认地址与模型为智谱免费那套；`llm.mode` 的 hint 说明新默认与兜底。
- `backend/src/api/routes/misc.ts`：`/api/summary` 里 `llmMode` / 模型名的硬编码 fallback 与常量一致。
- `frontend/src/routes/Settings.tsx`：免费模型预设下拉、三步引导卡、老用户提示；删掉「按 token 计费」旧文案。
- `backend/src/infra/llm/openai-compatible.ts`：401 / 402 / 429 / 404 的中文提示回指设置页引导。
- `docs/30-operations/免费大模型获取指南.md` + `README.md` 新增章节：口径一致，均标核对日期。
- `npm run typecheck` 与 `npm test` 全绿，零回归。

### 后续修订（2026-11-14）：默认模型换成 `glm-4.7-flash`

- **起因**：核对智谱官方[定价页](https://docs.bigmodel.cn/cn/guide/start/pricing)与[模型概览](https://docs.bigmodel.cn/cn/guide/start/model-overview)，当前免费文本模型清单已不含 `glm-4-flash`；页面明确「历史模型价格将继续保留，便于已有业务查询」，老名字随时可能不可用。
- **决定**：默认模型改为 `glm-4.7-flash`（官方免费档主力，200K 上下文，OpenAI 兼容，支持现有 `temperature` / `max_tokens`）。**本 ADR 的决策结构不变**：仍选 B、仍默认 `api`、仍保留 `web` 兜底、老库仍只提示不迁移；上文的 `glm-4-flash` 是当时的原文，保留不改。
- **新增约束**：该模型默认开启「深度思考」，短文本改写会变慢、更占免费档并发。请求体仅在「智谱域名 + 默认模型」时附加 `thinking: { type: 'disabled' }`；换服务商或换型号自动不附加，避免别家不认这个私有字段而报错。
- **注意**：老库里已存的 `llm.api.model` 不会被覆盖（`INSERT OR IGNORE`），老用户需在设置页重选一次「智谱」预设，或手动改这一项。

## Pros and Cons of the Options

### A：保持 `web` 默认

- Good, because 老用户零感知，零改动；ADR-13 字面不变。
- Bad, because 默认路径仍是最容易出错的一环，新人第一次用就可能卡在登录墙；「零费用」的卖点也没法在界面上兑现。

### B：默认 `api` + 免费模型（选中）

- Good, because 同时满足「不花钱」与「稳定」，且沿用项目里早已存在的 `api` 适配器，不是推倒重来。
- Bad, because 新人多一步注册；默认 Key 为空，第一次点发布会失败，需要引导兜住。

### C：默认 `api` + 沿用付费默认值

- Good, because 改动最小。
- Bad, because **直接违背 ADR-13 的「付费路径不许默认打开」**，新用户填免费 Key 也跑不通，是最容易踩坑的选项。

### D：B + 强制迁移老用户

- Good, because 全员立刻享受新默认。
- Bad, because 悄悄覆盖了用户显式存的 `app_config` 值；有人依赖 `web` 做离线改写，强制迁移会直接打断，违反 ADR-10 与「默认行为不悄悄改变」。
