## 一页说明

CHG-0003 把账号运营拆成了独立的「账号」页，但程序启动仍先进「工作台」，工作台只管当前账号，账号状态散在另一页。
本次把**工作台与账号页合并成一个统一的「启动」主界面**：程序启动即进入，以卡片集中展示每个账号的
**在线/离线、可用/异常、近期发布情况**，每个账号旁边一个独立的「发布」按钮，点哪个就只触发那个账号的全自动流程。

与核心发布工作流无关的信息（流水线轨、风险告警、合规说明、账号新建/删除/切换/检查/退出等管理动作）
**统一迁移到设置页**，主界面只保留「账号状态展示 + 发布操作」，减少干扰信息。

**明确不做**：一键开始全部账号（沿用 CHG-0002 Non-Goal）；不改发布工作流本身（`runOnce` 契约不变）；不新增后端接口/字段（复用 `/api/summary` 的 `accounts[]` 与现有账号/登录/熔断接口）。
