对外可见变化：

1. 程序启动即进入「启动」主界面，以卡片集中展示每个账号的**在线/离线、可用/异常、近期发布情况**。

4. 与核心发布无关的信息（流水线轨、风险告警、合规说明）与账号管理（新建/删除/切换/检查/退出）统一迁移到设置页。
