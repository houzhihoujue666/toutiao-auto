## 一页说明

CHG-0002 让一个进程能管多个账号，但账号的登录 / 切换 / 删除 / 新建仍散落在设置页，且没有「就地一键发布」的入口。
本次把多账号运营从设置页独立成一个「账号」页面（`/accounts`），每个账号行自带：

- 登录态、额度（今日/剩余）、队列深度、发布中数、待质检数、失败数
- 一个「条数」输入框（该账号一键发布的条数）
- 「一键发布」按钮：调用该账号的全自动流程；**该账号有待发布队列（queueDepth / reviewing / publishing 任一 >0）时禁用**，避免重复发起（与红线 9 同账号串行一致）
- 扫码登录 / 检查登录态 / 退出登录 / 切换 / 删除

设置页回归纯配置：可调设置 / 提示词模板 / 锁定项 / 外部账号与登录（LLM 等）/ 实现红线。

**明确不做**：一键开始全部账号（沿用 CHG-0002 Non-Goal）。
