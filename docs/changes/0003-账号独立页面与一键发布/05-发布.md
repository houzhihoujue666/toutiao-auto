# 发布记录

## 发布内容

- 对应变更包：`changes/0003-账号独立页面与一键发布/`
- CHANGELOG 分类：**Added**（独立「账号」页面 + 每行条数 + 一键发布 + 发布中禁用）

对外可见变化：

1. 顶栏导航新增「账号」页（`/accounts`），把多账号运营从设置页独立出来。
2. 每个账号行显示：登录态、当日额度/剩余、队列深度、发布中数、待质检数、失败数。
3. 每个账号行带一个「条数」输入 + 「一键发布」按钮，各自走全自动流程（采集→改写→配图→质检→发布）。
4. 账号处于发布中（queueDepth / reviewing / publishing 任一 >0）时，「一键发布」禁用，避免重复发起。
5. 设置页回归纯配置：账号列表与头条登录操作全部迁出，只保留可调设置 / 提示词模板 / 锁定项 / 外部账号与登录（LLM 等）/ 实现红线。

1. **设置页没有彻底删空账号相关内容**：LLM API 测试 / LLM 登录 / 当前账号熔断恢复仍留在设置页的「外部账号与登录」卡片——它们属于外部依赖，不是头条账号操作，按 REQ-0003-07 的边界保留，不算账号操作迁出遗漏。

3. **熔断提示文案**：设置页熔断标题由「当前账号已熔断」改回「账号已熔断」，以兼容既有 `settings.test.tsx` 断言，保持零语义改动。
