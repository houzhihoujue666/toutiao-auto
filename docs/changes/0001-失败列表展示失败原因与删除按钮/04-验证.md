## 过程中踩到的坑（登记，供后续参考）

1. **外键顺序**：`task.rewrite_id` 反向引用 `rewrite_result`，直接删改写稿会 `FOREIGN KEY constraint failed` → 先 `UPDATE task SET rewrite_id = NULL`。
2. **测试与自动流程抢状态**：集成测试里刚建的任务会被 tick 自动推进到 `publishing`，直接改状态再删会偶发 400 → 测试里先轮询等到终态（`published` / `failed`）再操作。
