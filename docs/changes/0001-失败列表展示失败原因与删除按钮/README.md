## 一页说明

失败列表原来只显示英文错误码（如 `SIMILARITY`），用户看不出为什么失败、也不知道该怎么处理；同时失败条目堆积后没有清理入口。
本次把错误码翻成人话（带阶段前缀、相似度实际值、悬停给处理建议），并给失败任务加「删除」按钮（二次确认），把这条任务连同改写稿 / 发布记录 / 日志一起清掉。

**明确不做**：批量删除；删除已发布/发布中的任务（要留证）；删除后的回收站与撤销。
