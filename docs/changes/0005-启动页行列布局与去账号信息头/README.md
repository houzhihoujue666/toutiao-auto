## 一页说明

CHG-0004 把工作台+账号页合并成「启动」主界面（卡片），并把账号管理/流水线/风险/合规迁进设置页。本次按 Owner 反馈优化：

1. **启动页改行列布局**：不再用卡片，每个账号占一行，行内含 数据看板、状态、登录按钮、发布条数、发布按钮，以及切换/删除等必要操作。
2. **明细页**：列表不变，账号切换放到最上方左侧。
3. **统一头部**：保留，但去掉一切账号相关信息（信用分、今日已发、账号切换下拉），只留标题与实时日志按钮。
4. **设置页瘦身**：删除与「设置参数」无关的内容（账号管理、流水线状态、风险告警、合规说明），只保留真正的可调参数。
