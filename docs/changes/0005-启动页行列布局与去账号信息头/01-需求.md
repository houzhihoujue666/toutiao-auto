# 需求文档 —— 启动页行列布局 + 头部去账号 + 设置页瘦身

## 背景

CHG-0004 合并出「启动」主界面（卡片形式）并设置页收口了一批非核心内容，但 Owner 反馈：
- 卡片太占空间，想要紧凑的「每行一个账号」列表；
- 统一头部里的账号信息（信用分、今日已发、账号切换）多余，应只在启动页看；
- 设置页被塞进了账号管理/流水线/风险/合规，不是参数，应删掉，只留设置参数。

## 验收标准

| 编号 | 标准 | 判定方式 |
| ---- | ---- | -------- |
| REQ-0005-01 | WHEN 打开启动页 THEN 每个账号以一行展示，行内含 数据看板、状态、登录按钮、发布条数、发布按钮及必要操作（切换/删除等） | 界面核对 / 单测 |
| REQ-0005-02 | WHEN 打开明细页 THEN 列表不变，账号切换控件位于页面最上方左侧 | 界面核对 / 单测 |
| REQ-0005-03 | WHEN 查看任意页面统一头部 THEN 不再出现账号相关信息（信用分、今日已发、账号切换），仅保留标题与实时日志按钮 | 界面核对 / 单测 |
| REQ-0005-04 | WHEN 打开设置页 THEN 仅保留与设置参数相关的内容（可调设置/提示词模板/锁定项/外部账号与登录/实现红线），删去账号管理、流水线状态、风险告警、合规说明 | 界面核对 / 单测 |

## Non-Goals

- 不改发布工作流（`runOnce` 契约不变）。
- 不新增/修改后端接口或 `shared/` 字段。
- 不重排明细页列表本身（只加左上切换）。

## 影响面

- 前端：App.tsx（头部）、Launcher.tsx（行列布局+账号管理）、Detail.tsx（左上切换）、Settings.tsx（删非参数卡）、styles.css。
- 后端 / 契约：无变更。
