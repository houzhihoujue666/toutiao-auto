# 设计文档 —— 启动页行列布局 + 头部去账号 + 设置页瘦身

## Context and Scope

CHG-0004 后的二次优化，纯前端重组。核心思路：**账号相关的所有信息与操作统一收口到启动页**，头部与设置页只留必要元素。

## 方案

### 1. 启动页行列布局（Launcher.tsx）
- 顶部工具条：标题 + 账号数 + 「新建账号」输入与按钮（`new-account-name` / `add-account`）。
- 每个账号一行（`<tr data-testid="launcher-account-<id>">`），列：账号 / 状态 / 数据看板 / 登录 / 发布条数 / 发布 / 操作。
  - 账号列：名称 + `当前` 徽标（若是 active）。
  - 状态列：`status-<id>` 徽标（在线/离线/异常·熔断/异常·登录失效）。
  - 数据看板列：今日 used/limit · 剩余 · 信用分 · 队列 · 发布中 · 待质检 · 失败 · 最后发布。
  - 登录列：`login-<id>` 扫码登录（未登录）/ `check-<id>` 检查登录态（已登录）。
  - 发布条数列：`run-count-<id>` 输入。
  - 发布列：`publish-<id>` 按钮（沿用 CHG-0004 禁用判据：发布中/离线/异常/额度耗尽）；`circuit==='open'` 时附 `resume-<id>` 恢复。
  - 操作列：`switch-<id>`（设为当前，active 时显示「当前」）/ `delete-<id>` 删除 / `reset-<id>` 退出登录（已登录时）。

### 2. 明细页左上切换（Detail.tsx）
- 在顶部 `.row`（tabs 行）最左加一个账号 `<select>`（`detail-account-switch`），`onChange` 调 `switchAccount`。列表按 activeId 重取（既有 effect 依赖已支持）。

### 3. 统一头部精简（App.tsx）
- 删除 `AccountPicker` 组件及其在 `topbar-r` 的渲染；删除 信用分 / 今日已发 两个 pill。
- 保留标题 + 实时日志按钮。
- 侧栏 `rail-ver` 去掉「账号 N 个」字样（仍显示方案/模式）。

### 4. 设置页瘦身（Settings.tsx）
- 删除卡片：账号管理、流水线状态、风险与告警、合规与风控（这些不是设置参数，且账号管理已迁启动页，流水线/风险/合规不属于参数）。
- 保留：可调设置、提示词模板、锁定项、外部账号与登录（承载 LLM 测试/登录，属外部依赖配置）、实现红线。
- 说明：合规（取材网络/头条首发）与熔断不自动恢复等规则**仍在代码层强制**，仅移除界面提示卡片。

## Alternatives Considered

- 设置页保留流水线/风险/合规卡片：与「只留设置参数」诉求冲突，否决。
- 头部保留一个轻量账号指示：Owner 明确要求去掉账号信息，否决。
- 启动页继续用卡片：Owner 明确要行列布局，否决。

## 文件清单

- `frontend/src/App.tsx`、`Launcher.tsx`、`Detail.tsx`、`Settings.tsx`、`styles.css`
- 测试：`launcher.test.tsx`（加账号管理）、`settings.test.tsx`（删迁移用例）、`e2e/pipeline.spec.ts`（多账号走启动页）

## 需要新决策吗

无。沿用 ADR-0015 与红线；不写新 ADR。
