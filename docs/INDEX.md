## 一、三层文档模型

| 层         | 目录                                                            | 是什么                                         | 能不能改                                   |
| ---------- | --------------------------------------------------------------- | ---------------------------------------------- | ------------------------------------------ |
| **常青层** | `10-architecture/` `20-reference/` `30-operations/` `00-guide/` | 系统"当前事实"：架构、接口、配置、操作、流程   | ✅ 随代码同步更新，改代码必须一起改        |
| **决策层** | `decisions/`                                                    | 一次决策及其理由（ADR）                        | ❌ 冻结；推翻时写新 ADR，老标 `superseded` |
| **变更层** | `changes/NNNN-xxx/`                                             | 一次功能变更的需求 / 设计 / 任务 / 验证 / 发布 | ❌ 批准即冻结；改动走新变更包              |
| **归档层** | `archive/`                                                      | 已完结、已取代、已废弃                         | ❌ 只读，永不删除                          |
| **沉淀**   | `postmortem/`                                                   | 事故复盘、经验教训                             | ✅ 可补充，不改结论                        |
